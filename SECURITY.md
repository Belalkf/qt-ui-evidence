# Sensitive reports

Captures can contain private text even though the JSON avoids widget text and object names. Use synthetic data and review images before sharing. The helper runs inside the application's process; import it only into a trusted, authorized test environment. Never feed untrusted application code to a test runner solely to inspect a screenshot.

This unpublished candidate has no hosted private-reporting channel. Report sensitive issues privately to the person who supplied your copy; do not post credentials or personal captures in a public issue. Before publication the maintainer must enable and verify the destination's private vulnerability reporting, then update this route. No response-time guarantee is offered.
