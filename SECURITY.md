# Sensitive reports

Report sensitive findings through [GitHub private vulnerability reporting](https://github.com/Belalkf/qt-ui-evidence/security/advisories/new). Do not post credentials or personal captures in public issues. No response-time guarantee is offered.

Captures can contain private text even though JSON avoids widget text and object names. Use synthetic data and review images before sharing. The helper runs inside the application's process; import it only into a trusted, authorized test environment. Never run untrusted application code solely to inspect a screenshot.

The comparison command reads only the operator-selected local evidence files, bounded to 2 MB each. The skill installer writes only to the explicitly selected user/project skill location and refuses an existing destination. These local paths are intentional operator choices, not permission to act on a path from an untrusted capture or website. Package installation runs no skill-installation hook, uses no network at runtime and stores no credentials.
